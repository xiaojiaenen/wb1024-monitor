# 1024 造物挑战 · 作品监控台

非官方的 **WorkBuddy「1024 造物挑战」程序员节应用创作大赛** 数据监控与 AI 分析应用。

实时同步官方活动页公开的作品墙与投稿池数据，用大模型按官方评审细则为每件作品生成模拟评分、技术栈推断与痛点分析，帮助参赛者了解竞争格局，帮助围观者快速发现好应用。

## 功能

- **实时监控**：作品墙上架数、投稿池审核结构（待审核/已通过/已驳回）、每日投稿趋势、最新投稿流水，60 秒同步
- **AI 评审团**：按官方细则（创意 35 + 完成度 40 + 体验 25，社媒潜力 30 参考）逐件生成模拟评分、一句话总结、痛点与解法、亮点、推断技术栈，全部附评分依据。批量管线（每批 6 件一次模型调用，调用量约为逐件调用的 1/6），结果写入云数据库全站共享缓存
- **作品库**：服务端分页（每页 24/48/96 条，页码与每页条数同步 URL 深链）、关键词/形态/平台筛选与多维排序（卡片号、AI 评分、社区人气、名称），图片点击弹灯箱看大图；作品详情按需拉取全量数据
- **数据洞察**：每日投稿量、上架趋势、AI 评分分布直方图、审核结构、平台分布、热门标签、社区人气榜
- **社区互动**：访客可为作品投票、收藏（本地随机访客 ID 去重，不采集个人信息），一键生成分享战报图片
- **降级兜底**：上游异常时保留最后快照展示；AI 模块故障不影响数据看板

## 技术栈

- **后端**：Node.js 原生 HTTP 服务（零第三方依赖），定时轮询 + 快照落盘 + 静态托管，读取 `PORT` 环境变量
  - `GET /api/snapshot`：全局快照（统计 / 投稿流水 / 趋势 / 洞察聚合），其中作品为**瘦身记录**（无长文本与多余截图，约 460KB）
  - `GET /api/works`：作品库**服务端分页**（`page`/`per`/`kw`/`form`/`platform`/`sort`），列表只返回当前页最小字段集；`only=ids` 返回全量 ID 列表供客户端按 AI 评分/人气排序，`ids=` 按给定顺序取页，`full=1` 返回全量记录（分析管线补数据用）
  - `GET /api/work?id=`：单件作品全量记录（详情模态框按需拉取，带内存缓存）
- **前端**：原生 HTML / CSS / JS 多页面 SPA（hash 路由），手写 SVG 图表，无构建步骤
  - 性能要点：作品列表服务端分页 + DOM diff 行复用（翻页/刷新不整表重建）、快照签名跳过未变化的渲染、定时器合并、截图懒加载
- **云服务**（WorkBuddy Cloud）：免密钥大模型调用生成作品分析；云数据库（PostgreSQL + RLS）持久化分析结果与互动数据
  - **免费模型调度**（`public/cloud.js`）：`step-5-preview`（全天免费）为白天主力，`hy4-preview`（夜间 23:00–次日 08:00 活动免费窗口）为夜间主力，`hy3`（全天免费）兜底；单个模型失败自动切换下一个，全部不可用则暂停 30 分钟后自动重试，期间队列保留不丢失
- **设计系统**：赛事识别方向（Otl Aicher 慕尼黑奥运识别系统血统）——冷白纸底 + 单一信号橙红 + 黑色状态带 + 象图导航

## 隐私与边界

- 仅采集活动**公开**的作品与投稿信息；官方存放联系电话的隐私表**不在采集范围内**（代码层面已隔离，其表 ID 不写入任何代码与注释，见 `server.js` 头部说明）
- 互动功能仅在浏览器本地生成随机访客 ID 用于投票/收藏去重，不采集任何个人身份信息
- `public/cloud.js` 中的 `publishableKey` 是 WorkBuddy Cloud 平台下发的**可公开密钥**（与 Supabase anon key 同类）：仅用于标识应用、不携带账号权限，所有数据访问受云数据库 RLS 策略约束。仓库中不含任何 secret key
- AI 评分为**模拟评审**，与官方评审结果无关，不构成获奖预测

## 本地运行

```bash
node server.js
# 默认 http://localhost:3000 ，可通过 PORT 环境变量修改
```

## 目录

```

package.json         项目元信息（无依赖）
public/
  index.html         应用外壳（象图导航轨 + 状态带 + 页面容器）
  styles.css         设计系统（赛事识别方向）
  app.js             六页应用逻辑 + 图表 + 互动 + 分享战报
  cloud.js           WorkBuddy 云服务封装（LLM 免费模型调度 + 数据库）
  analysis.js        AI 分析管线（启动 hydration → 批量队列 → 落库）
LICENSE              MIT
```

## 风险提示

本应用依赖对官方活动页数据接口的解析。**若官方调整页面结构或接口，部分功能可能暂时失效**；此时将以最后一次成功快照继续展示，并尽快修复。
