# 「1024 造物挑战」作品监控台 — 设计 Spec 与六张方向卡

## Spec（三个方向的共同输入）

**项目是什么**：WorkBuddy「1024 造物挑战」程序员节应用创作大赛的**非官方社区监控台**——抓取官方公开数据表，实时呈现投稿流水、审核状态、作品库与 AI 评审榜。已上线功能：6 页应用（总览/作品库/AI 评审/数据洞察/实时动态/关于）、AI 逐件分析（GLM-5.3-flash，云数据库缓存）、搜索、图表、详情抽屉、深链。

**受众**：参赛者（关心自己的作品与排名）、围观的开发者、WorkBuddy 社区围观群众。核心场景：桌面端闲暇时打开，"现在比赛什么情况了"。

**核心信息分点**：
1. 实时性——投稿在流进来（今日 +681）、倒计时（投稿截止 11-01，剩 9 天）、审核漏斗（待审核 2041 / 已通过 553 / 已驳回 235）
2. 作品库——已上架 654 件，每件有真实截图、宣言、体验链接
3. AI 评审榜——按官方评分细则（创意35/完成度40/体验25）逐件打分，已分析 15 件，排行 + 分项理由
4. 数据洞察——每日投稿趋势、平台分布、形态分布（网页应用 626 / 小程序 28）

**情感基调**：专业可信（数据诚实、不编造）、有速度感（实时流动）、程序员节的极客氛围。用户原话约束："不要 AI 味"、"专业到甚至能作为 workbuddy 官方的监控网站"、"设计像真正的网站，不要一直垂直下滑"。

**输出格式与尺寸（三版统一）**：桌面 Web 应用，主视口 1440×900。每版初稿包含：应用外壳（导航 + 顶栏）+ 总览页（KPI + 趋势 + 最新作品 + 实时流水）+ AI 评审榜页（证明系统成立，不是一屏垂直下滑）。内容三版完全一致，只换设计。

**已知约束**：不用紫色渐变、不用玻璃拟态光效、不用 emoji 图标、不删模板装饰（全大写小标签行、A·B·C 中点、按钮 →、01/02/03 编号）；中文界面；数据全部真实（冻结快照 + 15 件真实 AI 分析）；含"官方可能修改网页结构导致失效"提示条。

**图片需求**：作品真实截图（workbuddy CDN，作品墙 12 件首图）——内容必需的图，先取齐。

## 六张方向卡

### 卡 1 · 最佳设计师｜Otl Aicher（慕尼黑 1972 奥运会识别系统）
- **逻辑与来源**：Otl Aicher 为 1972 慕尼黑奥运会设计的识别系统——赛事史上最著名的"事件即系统"设计。比赛本身是事件，监控台就是它的成绩处理中心。
- **借的是什么**：① 严格栅格 + 发丝线分栏；② 一套几何象图（pictogram）做分类导航——用几何 SVG 图标代替 emoji；③ 单一信号色（奥运橙红）只给"状态/进行中"用，其余黑白；④ Condensed grotesque 大标题；⑤ 表格数字（tabular numerals）做所有计数；⑥ 结果榜（results board）母题：rank / name / score 三列。
- **主角素材**：作品真实截图缩略墙 + 超大表格数字。
- **骨架**：左列象图导航 + 主区多面板栅格；顶部一条赛事状态带（倒计时 + 三个大计数）。
- **胆量花在哪**：AI 评审榜整页做成奥运会结果榜——大序号、大分数、细分级。
- **form 来自内容的哪里**：比赛是事件，监控台是事件的成绩处理中心——体育赛事的信息设计语法直接迁移。

### 卡 2 · 最佳设计师｜Edward Tufte（数据墨水）
- **逻辑与来源**：Tufte《The Visual Display of Quantitative Information》——data-ink 最大化、去 chartjunk、小倍数、直接标注。监控台的价值全在数据，每个像素都该携带信息。
- **借的是什么**：① 去掉一切不承载数据的装饰（无卡片阴影、无圆角、无渐变）；② sparkline 嵌进每一行数字（每件作品、每个 KPI 自带 48 分钟趋势）；③ 图表直接标数值，不用图例；④ hairline 网格 + 1px 分隔；⑤ 衬线标题（ET Bembo 气质）+ 无衬线数据；⑥ 单一强调色只标"正在发生的事"。
- **主角素材**：数据即图像——sparkline、小倍数图阵、直接标注的柱状图。
- **骨架**：单页多面板"仪表盘纸"，左侧窄导航，右侧密集面板流；所有图表小倍数化。
- **胆量花在哪**：Overview 全部图表去掉坐标轴与网格装饰，数字直接标在图形上。
- **form 来自内容的哪里**：监控台 = 数据仪器；仪器的诚实形态就是高数据墨水比。

### 卡 3 · 现实参照｜FT Pink Paper（markets.ft.com，已截图 refs/ref-ft.png）
- **逻辑与来源**：FT 自 1893 年的鲑鱼纸 + 2014 Financier/MetricWeb 定制字体系统，markets 数据页是"机构级实时数据"的设计标杆。已核实并截图。
- **借的是什么**：① 鲑鱼纸底 #FFF1E5 当品牌画布；② 海军蓝 #262A33 墨色；③ teal #0D7680 唯一 accent（链接/CTA/焦点）；④ 衬线 display（600 字重克制）+ 无衬线数据字；⑤ 表格数字；⑥ 1px 暖灰 hairline #CDC6C0；⑦ 实时更新单元格闪烁（cell-flash）；⑧ claret #990F3D 只做 kicker 标签。
- **主角素材**：纸感画布 + 密集数据面板 + 白卡片浮起。
- **骨架**：报刊式 masthead（报名 + 导航条）+ 多栏密集面板；顶栏实时计数。
- **胆量花在哪**：实时投稿流水做成 FT 式 ticker——新投稿到达时对应单元格闪一下。
- **form 来自内容的哪里**：实时数据出版——监控台就是一份持续付印的"赛事数据报"。

### 卡 4 · 现实参照｜GitHub Trending（已截图 refs/ref-ghtrending.png）
- **逻辑与来源**：GitHub Trending 是开发者最熟悉的"实时榜单"形态。已核实并截图。
- **借的是什么**：① 排名卡解剖（序号 + 名称 + 描述 + meta + 今日增量 delta）；② 筛选 chip 行；③ 语言色点；④ star 按钮 + "stars today" 右列 delta；⑤ 白底 + 深色顶栏。
- **主角素材**：作品截图卡 + delta 列。
- **骨架**：标准产品 UI：深色顶栏 + 筛选 chips + 排名列表卡。
- **胆量花在哪**：每张作品卡右侧一列"今日 AI 评分变化"。
- **form 来自内容的哪里**：把"今日热榜"这个开发者肌肉记忆形态直接迁移到作品榜。

### 卡 5 · 秒数轮盘｜网页 #13 Glassmorphism Bento（样张 sheet-web.jpg 第 13 格，已看）
- **逻辑与来源**：Linear/Cursor 带起的"暗色发光 bento"流派，监控工具的 genre 默认形态。轮盘抽中（秒数 32 % 20 + 1 = 13）。
- **借的是什么**：① 近黑底 #08090A；② bento 分块网格；③ 单一品牌微光（去饱和蓝紫，只做焦点指示不做氛围）；④ 发丝分割线。
- **主角素材**：暗底上的作品截图 + 数据块。
- **骨架**：暗色 bento 网格 dashboard。
- **胆量花在哪**：排行榜暗底卡片 + 分数发光条。
- **form 来自内容的哪里**：控制台/暗室——长时间盯屏的监控工具形态。
- **风险备注**：与用户明确拒绝的"AI 味"外观距离最近，列为备选；若做需去掉渐变光晕只留结构。

### 卡 6 · 秒数轮盘｜东亚 #9 田中一光几何平面构成（样张 east/09，已看）
- **逻辑与来源**：田中一光把日本传统与国际主义融合的几何构成（《日本舞踊》1981；西武剧场/无印良品视觉）。轮盘抽中（32 % 12 + 1 = 9）。"造物节"是节庆，节庆有自己的识别系统。
- **借的是什么**：① 米纸底 + 红 #D9381E + 黑 + 芥黄 #E8B93B 四色；② 方/圆/四分之一圆在网格上拼构成主图；③ 竖排粗宋体大标题；④ 信息块小红标签分组；⑤ 底部一条细黑线。
- **主角素材**：几何构成主图 + 作品截图网格。
- **骨架**：节庆识别系统：首屏几何主图 + 竖排标题 + 信息分块；作品墙按几何网格策展。
- **胆量花在哪**：作品墙按几何构成策展（非等距卡片流）。
- **form 来自内容的哪里**：造物节是节庆——节庆海报的识别语法。

## 挑选结论（Phase 4d）

按 ① 单看就够好 ② 三张彼此不一样（骨架/气质/温度）③ 不撞账本（空账本）④ 不用力过头，入选完整版：

- **完整版 1 = 卡 1（Aicher 赛事识别）**：冷白 + 信号橙红 + 象图导航，大胆/运动感
- **完整版 2 = 卡 3（FT 数据纸刊）**：暖鲑鱼纸 + 衬线 display + 实时闪烁，暖/机构感
- **完整版 3 = 暗房仪表（卡 5 暗色骨架 + Tufte 数据密度基因）**：纯黑底 + 作品截图供色 + 单一琥珀 accent，暗/仪器感

备选（随 thumbs 一并向用户展示）：卡 2（Tufte 白纸仪器）、卡 4（GH Trending 排名卡解剖）、卡 6（田中一光节庆几何）。

**换版记录（Phase 5 中）**：初版完整版 3 为 Tufte 白纸仪器，`design_lint.py compare` 判定三版色板距离全部 <0.03、同落「细线报纸」外观家族（一种气质的三个变体）。按规则"撞了的那版回到方向卡重做：换骨架或换来源，不是换颜色"，将 dir-3 重做为暗房仪表方向：保留 Tufte 的直接标注/sparkline/密度基因，换成纯黑画布（#0B0B0C）+ 琥珀单 accent（#F2A93B）+ 截图供色的画廊式作品呈现。Tufte 白纸版降级为备选。
